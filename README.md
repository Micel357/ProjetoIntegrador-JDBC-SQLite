# Projeto Integrador — JDBC e SQLite

Repositório reservado para um projeto Java com JDBC e SQLite.

**Estado atual:** apenas este README está versionado. Ainda não há código-fonte, testes, arquivo de build ou banco de dados no repositório. Por isso, não há comandos de compilação ou execução disponíveis.

Quando a implementação for adicionada, a organização recomendada é manter o arquivo de build na raiz, usar `src/main/java/` para a aplicação, `src/test/java/` para testes e `docs/` para decisões técnicas. Arquivos `.db` gerados localmente devem ficar fora do controle de versão.
